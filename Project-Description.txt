Project: AI Study Assistant

You will build a real full-stack AI application for students.

The user can:

Create an account / log in
Upload lecture notes/PDFs
The system processes the documents
Ask questions about their notes
Get answers grounded in their documents
View chat history
Generate summaries
Generate quizzes from their notes
Eventually use an AI agent that can perform study-related actions

The important part: we will build it progressively. You don't need to know everything before starting.
