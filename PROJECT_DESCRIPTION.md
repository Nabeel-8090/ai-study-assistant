# AI Study Assistant

An evolving AI-powered study assistant built to learn and apply **AI engineering and backend development** through incremental versions.

The project starts with a basic LLM-powered chat application and gradually evolves into a full AI study assistant with authentication, document processing, RAG, production backend features, and agentic AI workflows.

## Project Versions

| Version | Name | Description |
|---------|------|-------------|
| **V01** | Basic AI Chat | Basic chat application using **React + TypeScript + Vite**, **FastAPI**, and the **Gemini API**. Establishes frontend-backend communication and LLM API integration. |
| **V02** | Backend Foundation | Improve the FastAPI backend structure and implement validation, error handling, logging, configuration, and cleaner API architecture. |
| **V03** | Authentication & Database | Add **PostgreSQL**, user accounts, authentication, authorization, conversations, and persistent chat history. |
| **V04** | Document Processing | Allow users to upload study materials such as PDFs and process, extract, and store their content. |
| **V05** | RAG | Add embeddings, vector search, and **Retrieval-Augmented Generation (RAG)** so users can ask questions based on their uploaded study material. |
| **V06** | Production Engineering | Improve reliability and scalability with caching, rate limiting, background jobs, queues, monitoring, and other production backend concepts. |
| **V07** | Agentic AI | Introduce agentic workflows and tool calling so the assistant can perform tasks such as searching notes, generating quizzes, summarizing material, and creating study plans. |
